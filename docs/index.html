Run it on your gaming PC.

  1. Download and extract the project. Install Python 3.12 if needed.
  2. Run the included demo-support installer, then start the local helper.
  3. Add your own FACEIT server-side Data API key in the local setup page.
  4. Load the extension folder in Chrome or Edge using Developer mode, and pair it with the helper.

Project status

Version 0.1 is an installable personal build. The core checks, extension plumbing and native replay parsing have been tested. Live authenticated FACEIT access, scouting accuracy and real-match latency still need validation.

The project does not include a populated global player database. Position information depends on the demos available to your local helper.

Privacy and data use

This project website is a static page hosted on GitHub Pages. It contains no analytics scripts, account forms or application API endpoints. GitHub operates the hosting infrastructure under its own privacy policy.

The extension and local helper

  • The browser extension connects to a paired helper on your own computer.
  • Your FACEIT API key is stored in the local helper configuration. It is not embedded in the public source or sent to this website.
  • The helper requests public match and player information from FACEIT and analyses accessible demos of completed matches.
  • Derived evidence is cached locally for recent matches. Downloaded demo files are deleted after extraction.
  • No external AI service or telemetry is used by this build.

For questions or bug reports, use GitHub Issues. Do not post API keys, pairing codes or private configuration files.
